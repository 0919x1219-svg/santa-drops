# Santa's Drop

## Repository
https://github.com/0919x1219-svg/santa-drops

## Description
A Christmas arcade game made with Python and pygame where Santa flies over a town, dodges obstacles, and drops a limited number of presents into chimneys. It combines pixel-style game art, animation, and interactive design.

## Features
- Santa movement and flying
	- Arrow keys move Santa up and down while the background scrolls automatically.
- Obstacles
	- Birds, power lines, and planes spawn at random, and hitting one takes away a life.
- Present dropping
	- Space bar drops a present that falls with gravity, and each level has a limited number of presents.
- Chimney scoring
	- Collision detection checks if a present lands in a chimney to give points.
- Levels and game states
	- Menu, gameplay, and game over screens, with more obstacles and fewer presents in later levels.
- Sound and effects
	- Background music, sound effects, and snow particles.

## Challenges
- Learning pygame basics like the game loop, sprites, and collision detection.
- Making the present drop feel natural with simple gravity.
- Managing game states and organizing the code into functions and classes.

## Outcomes
Ideal Outcome:
- A polished multi-level game with custom art, animations, sounds, and a score system.

Minimal Viable Outcome:
- One playable level where Santa moves, avoids obstacles, drops a limited number of presents, and scores points on chimney hits.
